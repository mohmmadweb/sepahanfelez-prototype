# پروتوتایپ رابط کاربری سپاهان فلز

نسخه‌ی نمایشی طراحی جدید `sepahanfelez.ir` — HTML/CSS خالص، بدون فریم‌ورک،
بدون جاوااسکریپت، بدون وابستگی خارجی.

**نمایش زنده:** https://sepahanfelez.lenzit.ir

## صفحات

| صفحه | نقش |
|---|---|
| [`index.html`](index.html) | صفحه اصلی — نوار تولیدکننده، شاخص قیمت، جدول تغییرات، ۱۰ دسته |
| [`price.html`](price.html) | جدول قیمت کل با ستون مشخصات فنی و نوار ابزار |
| [`category.html`](category.html) | صفحه دسته (توری حصاری، ۱۳ کد واقعی) با ماشین‌حساب و فیلتر |
| [`product.html`](product.html) | صفحه محصول تکی با کارت قیمت و نمودار |
| [`report.html`](report.html) | گزارش کامل تحلیل رقبا و بازطراحی |

## نکات

- **این نسخه `noindex` است.** محصولات عیناً همان‌های سایت اصلی‌اند و ایندکس
  شدنشان محتوای تکراری می‌سازد. `robots.txt` هم کل مسیر را می‌بندد.
- قیمت‌ها و مشخصات فنی از `sepahanfelez.ir` در ۱۶ مرداد ۱۴۰۵ برداشته شده‌اند.
- فونت IRANSans FaNum لوکال است؛ صفحه بدون اینترنت هم درست رندر می‌شود.
- بلوک‌های آبی داخل صفحات، یادداشت‌های فنی پروتوتایپ‌اند و در نسخه‌ی نهایی
  حذف می‌شوند.

## کیفیت

چهار صفحه در ۱۳ عرض از ۳۶۰ تا ۱۹۲۰ پیکسل تست شده‌اند:
صفر اسکرول افقی · صفر ناحیه لمس زیر ۴۴px · صفر آیکون شکسته ·
صفر تصویر بدون alt · دقیقاً یک H1 در هر صفحه.
