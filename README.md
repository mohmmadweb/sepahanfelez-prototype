# پروتوتایپ رابط کاربری سپاهان فلز

بازطراحی `sepahanfelez.ir` — فروشگاه اینترنتی کارخانه‌ی **صنایع مفتولی طلوع سپاهان**.
HTML/CSS ایستا، بدون فریم‌ورک، سه فایل جاوااسکریپت کوچک برای بهبود تدریجی.

## صفحات (۱۲۲ صفحه)

| نشانی | محتوا |
|---|---|
| `/` | اسلایدر · دسته‌های محصول (بدون قیمت) · مزیت‌ها · سه واحد (دو کارخانه + دفتر تهران، با ویدئوی هوایی) · مجله |
| `/price` | **قیمت لحظه‌ای**: آخرین تغییرات قیمت · ۹ جدول فشرده با ستون‌های کلیدی · جست‌وجوی سراسری · فهرست پرش |
| `/category/{slug}` | ۹ صفحه‌ی دسته: آمار، عکس، جدول با فیلتر، راهنمای خرید، مشخصات کامل، FAQ، مقالات مرتبط |
| `/category/{slug}/{product}` | ۷۰ صفحه‌ی محصول: گالری، کارت قیمت، مشخصات، قیمت قابل‌مقایسه، نکات خرید، هم‌دسته‌ها، مقالات مرتبط |
| `/blog`, `/blog/{cat}`, `/blog/{cat}/{article}` | مجله به سبک دیجی‌کالا مگ: ۳۱ مقاله‌ی واقعی سایت در ۶ دسته، با «محصول مرتبط» زیر هر مقاله |
| `/about`, `/contact`, `/category/` | درباره‌ی کارخانه، تماس (با نقشه‌ی دفتر تهران)، فهرست دسته‌ها |

نشانی‌ها عیناً همان روت‌های بک‌اند لاراول است (`routes/web.php` در مخزن Ahanamn).

## ساخت

```
python3 build/gen.py        # همه‌ی صفحات را می‌سازد (فقط پایتون ۳ استاندارد)
```

```
build/gen.py        سازنده — ارقام فارسی را در پایان روی HTML اعمال می‌کند
build/common.py     کمکی‌ها، تاریخ شمسی، نشانی‌ها، سر و پاصفحه
build/pages.py      صفحه‌ی اصلی، قیمت لحظه‌ای، دسته، محصول، درباره، تماس
build/tables.py     جدول قیمت فشرده (الگوی آهن آنلاین)، جدول تغییرات، مشخصات
build/blog.py       مجله: داده، ربط مقاله↔محصول، صفحات
build/content.py    متن‌های سایت، دسته‌ها، شماره‌ها، نشانی‌ها
build/analysis.py   اقتصاد هر محصول (قیمت هر m²/kg/رول) و نکات خرید
build/catalog.json  ۷۰ نوع کالا در ۹ دسته — برداشت از سایت زنده
build/articles.json ۳۱ مقاله‌ی سایت زنده، پاک‌سازی‌شده
build/photos.json   عکس‌های هر دسته (assets/products/)
assets/app.css      سیستم طراحی، با توضیح فارسی هر تصمیم
assets/site.js      تاریخ زنده، جست‌وجوی سراسری قیمت، گالری محصول
assets/table.js     فیلتر جدول دسته · assets/hero.js اسلایدر
sepahanfelez-catalog/  کاتالوگ چاپی A4 (جدا از سایت)
```

## قواعد ثابت

- قیمت‌ها به **ریال**، مبنای روز درب کارخانه؛ بروزرسانی هر روز ساعت **۱۲:۳۰**.
- قرمز برند فقط برای «تماس». متن پایه ۱۸px دسکتاپ / ۱۷px موبایل. هیچ ناحیه‌ی لمس زیر ۴۴px.
- «نوع کالا» به‌جای «کد کالا». هیچ‌جا «ارزش افزوده جداگانه محاسبه می‌شود» نمی‌آید.
- محتوا عین سایت اصلی است؛ این نسخه `noindex` است تا محتوای تکراری نسازد.
